# Course Overview

Learn to master the foundational developer tools you need for modern work. This course teaches you how to use mise to manage multiple dev tools efficiently, set up a complete local development environment on your Mac, and learn VSCode as a bridge to AI-assisted file management—not as a complex code editor.

After completing this course, you'll have a professional dev environment ready for daily use. You can install and manage tools with mise, organize projects cleanly on your machine, and collaborate with AI by precisely directing it to edit specific files through file paths.
