# VSCode 极简指南：为 AI 打造的文件管理中枢

> 为什么把 VSCode 当作**文本编辑器 + AI 助手**，而不是代码编辑器？因为这样，你就可以让 AI 接管你的文件管理、文档管理、甚至信息管理的工作。

## 🎯 这个课程的真实目标

你可能听过 VSCode，也可能以为它是"专门给程序员写代码用的"。其实不是。

在我们接下来的学习中，VSCode 的真正价值是：**成为你和 AI 之间沟通的桥梁**。

想象一下这样的工作流：
1. 你打开一个文件夹（你的项目）
2. 你用鼠标快速找到某个文件，复制它的路径
3. 你把这个路径告诉 AI："嘿，请帮我编辑这个文件"
4. AI 根据路径准确找到文件，进行修改
5. 你用 GitHub Desktop 保存这些更改

这就是现代工作方式：**人类做决策和指导，AI 做具体的文件操作**。

我们先掌握这个基础。至于"写代码"这件事，那是以后需要的时候再学。现在，我们的目标就是学会怎样用 VSCode 来管理文件、让 AI 能够理解你要改什么。

## 📥 第 1 步：下载 VSCode — 准备工作环境

访问 [code.visualstudio.com](https://code.visualstudio.com)，下载 Mac 版本，拖入应用程序文件夹。

就这么简单。VSCode 就是一个工具，我们不需要复杂的配置，开箱即用就行。

## 📂 第 2 步：打开一个文件夹 — 定义你的"工作区"

现在，我们来讲 VSCode 最核心的概念：**Project**（项目），其实就是一个文件夹。

为什么这很重要？因为 AI 需要知道你在处理的是哪个项目。一个文件夹通常对应一个 GitHub 仓库。当你打开一个文件夹作为项目后，VSCode 就会显示这个文件夹里的所有文件和子文件夹，形成一个清晰的目录树。

**有什么用？**
- 你能一目了然地看到项目的整个结构
- 当你告诉 AI"请编辑某个文件"时，AI 可以在这个上下文中准确理解你的指令
- 你随时可以快速浏览和找到任何文件

**如何打开：**

1. 打开 VSCode
2. 点击菜单 `File` → `Open Folder...`
3. 选择你的项目文件夹（比如你从 GitHub Desktop 克隆下来的代码仓库）
4. 完成 — 这个文件夹现在就是你的工作区间，左边的文件树会显示所有内容

![打开文件夹](./imgs/03-Open-Github-Repo-in-VSCode/03-Open-Github-Repo-in-VSCode-01.png)

## 🔑 第 3 步：复制文件路径 — 告诉 AI "我要改这个"

这一步非常重要，是整个工作流的关键。

当你要让 AI 修改某个文件时，你不能模糊地说"改一下那个 app 文件"。AI 需要一个精确的地址：**完整的文件路径**。

比如你想修改一个配置文件，你需要告诉 AI：
```
/Users/yourname/Documents/GitHub/my-project/config.json
```

而不是"改一下 config 文件"。

**最简单的方法：右键点击文件，选择 `Copy Path`**

这样就会自动复制完整路径到剪贴板。然后你就可以直接粘贴给 AI。这是你和 AI 之间最高频的交互。

![复制路径](./imgs/03-Open-Github-Repo-in-VSCode/03-Open-Github-Repo-in-VSCode-03.png)

**为什么这么重要？**

因为这是让 AI 精确操作你的文件的唯一方式。没有准确的路径，AI 就不知道你想改哪个文件。掌握这个操作，相当于掌握了和 AI 沟通的"共同语言"。

## 📋 第 4 步：掌握文件操作 — 日常的管理能力

VSCode 让你能够快速地浏览、查找、编辑和管理文件。这些看起来很基础，但它们是你每天都会用到的。

### 搜索文件 — 快速定位

项目中的文件很多。你不可能记住每个文件的位置。所以最重要的技能是：**快速搜索**。

在 VSCode 中，按下 `Cmd + P`（或点击左上角的搜索图标），然后输入文件名的一部分。比如你想找 `config.json`，就输入"config"，VSCode 会立刻显示所有包含"config"的文件。

**有什么用？**
- 节省时间 — 不用在文件树里一层层点击
- 减少错误 — 快速找到正确的文件，避免改错了位置
- 当你告诉 AI"我想在 config 文件里加一行"时，你自己先找到对应的文件，才能准确地告诉 AI 要改哪个

![搜索文件](./imgs/03-Open-Github-Repo-in-VSCode/03-Open-Github-Repo-in-VSCode-02.png)

### 常见的文件操作

当你日常使用 VSCode 时，这些操作会频繁出现：

| 操作 | 方法 | 为什么有用 |
|------|------|----------|
| **打开文件** | 双击左边的文件树 | 查看文件内容，确认要改什么 |
| **编辑文件** | 打开文件后直接输入 | 做快速的小改动 |
| **保存文件** | `Cmd + S` | 确保修改被保留 |
| **删除文件** | 右键 → Delete | 清理不需要的文件 |
| **移动文件** | 右键 → Move | 重新组织项目结构 |
| **重命名** | 右键 → Rename 或双击文件名 | 改变文件名，保持项目清晰 |
| **复制路径** | 右键 → Copy Path | **最关键** — 告诉 AI 要改哪个文件 |
| **在文件间切换** | 点击上方的标签页 | 在多个文件之间快速切换 |

### 查找和替换

有时你不仅要找到文件，还要在文件内容里搜索特定的词。按 `Cmd + F` 打开查找功能，输入你要找的内容，VSCode 会高亮显示所有匹配的地方。

如果你要替换这些内容，按 `Cmd + H` 打开"查找和替换"，可以一次性改多个地方。

**为什么有用？**
- 比如你想改一个函数的名字，需要改代码里所有的地方，用"查找和替换"比手动逐个改快得多
- 你可以准确地看到改动会影响哪些地方

## 🔗 第 5 步：三工具的协作 — 完整的工作流程

现在你已经掌握了 VSCode 的基础。但 VSCode 不是独立工作的，它是和 GitHub Desktop 配合的。

这是一个完整的工作流程：

1. **GitHub Desktop**：你用它来克隆（下载）项目到你的电脑。比如你从 GitHub 上找到了一个项目，用 GitHub Desktop 把它下载到你的 `Documents/GitHub/` 文件夹
2. **VSCode**：你用它打开这个文件夹。现在左边的文件树显示了整个项目的结构
3. **你**：你浏览文件，找到想修改的地方，复制它的路径
4. **AI（通过 Claude Code）**：你把路径告诉 AI，AI 根据路径找到文件并进行修改
5. **GitHub Desktop**：修改完成后，你用 GitHub Desktop 提交（commit）和推送（push）你的更改回到 GitHub

这个工作流的美妙之处在于：**人类做决策，AI 做执行**。你只需要说"我想改这个文件"，AI 就能精确地找到它、修改它。

**为什么这样工作很有效？**
- 你专注于思考和决策，不用被繁琐的编辑工作分散注意力
- AI 可以快速、准确地执行你的指令
- 整个过程清晰可追踪，GitHub Desktop 会记录每一次改动

## 💡 核心理念：正确理解 VSCode 的角色

很多人学 VSCode 时，会陷入一个误区：觉得 VSCode 是"代码编辑器"，所以要学会在里面写代码。

其实不是。在这个阶段，你需要理解的是：

- **VSCode 是信息管理工具** — 帮你浏览、查找、组织文件
- **文件路径是沟通工具** — 你通过路径告诉 AI"请改这个地方"
- **右键 Copy Path 是最高频操作** — 这是你和 AI 沟通的方式

写代码这件事，我们以后再学。现在，先掌握如何让 AI 接管你的文件操作。一旦你学会了这个，你会发现生活变得简单了很多：文件管理、文档编辑、配置修改，都可以让 AI 帮忙。

## 👨‍🏫 教师笔记：为什么设计成这样？

### 学生常见的误区

当我们说"学 VSCode"时，很多人以为要学会在里面"编程"。所以他们会陷入麻烦：去学快捷键、学插件、学各种高级功能。结果被吓怕了。

但这是错的方向。

### 课程的真实意图

这个课程要建立的**心智模型**只有一个：**VSCode 是人和 AI 沟通的媒介**。

你需要学会的技能非常有限：
1. **打开一个文件夹** — 定义你的工作区
2. **快速搜索文件** — 找到你要改的东西
3. **复制文件路径** — 告诉 AI"请改这个"

就这三个。

其他 VSCode 的功能（调试器、扩展、主题、快捷键等等），都可以以后慢慢学。我们不需要一开始就全学。

### 为什么要分离"文件管理"和"代码编写"？

一个重要的观点：**文件管理和代码编写是两个不同的能力**。

- 文件管理 = 知道文件在哪里、怎么改、怎么保存
- 代码编写 = 知道怎么写出能工作的代码

在 AI 时代，这两个能力的重要性是反过来的：
- **文件管理变得更重要了** — 因为你需要精确地告诉 AI"改这个文件"
- **代码编写变得不那么重要了** — 因为 AI 可以帮你写代码

所以我们先专注于文件管理。一旦学生掌握了这个，他们就可以立刻开始和 AI 协作。代码的部分，以后自然会学。

### 课程的延续性

这个课程是一个"垫脚石"。学会了这个，接下来你可以：
- 让 AI 帮你创建新文件
- 让 AI 帮你修改配置文件
- 让 AI 帮你编写文档
- 让 AI 帮你做任何涉及"文件操作"的事

最后，当你真的需要写代码时（比如学 Python），VSCode 只是你已经熟悉的工具，不是新的挑战。
