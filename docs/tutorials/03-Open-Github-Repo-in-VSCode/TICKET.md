# Task: Open a GitHub Repo in VSCode and Master File Paths

**Goal:** Learn to open a project folder in VSCode and practice copying file paths — the foundation for communicating with AI.

Read the [Tutorial](https://github.com/easyscale-academy/learn_dev_tools_basic-project/tree/03-Open-Github-Repo-in-VSCode/)

**Estimated time: 15–20 minutes**

---

## 📋 What You'll Do

By the end of this task, you'll be able to:
- Open any project folder in VSCode
- Navigate the file tree quickly
- Copy any file's full path with one right-click
- Search for files by name

This is the core skill for telling AI exactly which file you want to edit.

---

## 🎯 Step-by-Step Instructions

### Part 1: Open a Project Folder

1. Open VSCode (you installed this in Lesson 02)
2. Click `File` → `Open Folder...`
3. Navigate to a project folder on your Mac
   - If you cloned a repo with GitHub Desktop, use that folder
   - If not, create a test folder in your Documents to practice with
4. Click "Open"
5. You should see a file tree on the left side showing all files and folders

**Why this matters:** This folder is now your "project context." Everything you and AI do happens within this folder.

### Part 2: Practice Copying File Paths

1. Look at the file tree on the left
2. Find any file (a README, config file, or any text file)
3. Right-click on it
4. Select `Copy Path`
5. Paste it into a text editor or your notes
6. You should see the full path, something like:
   ```
   /Users/yourname/Documents/my-project/filename.txt
   ```

**Do this 3 times** with different files. Get comfortable with the action.

**Why this matters:** This full path is how you tell AI "please edit this specific file." Without it, AI won't know which one you mean.

### Part 3: Search for Files

1. Press `Cmd + P` (or click the search icon at the top left)
2. Start typing part of a filename you know exists
   - Try typing just the first few letters
3. VSCode shows you matching files
4. Click one to open it
5. Notice which file opened — that's the one you told it to find

**Do this 3 times** with different filenames.

**Why this matters:** You won't remember every file's location. Quick search saves you time and prevents mistakes.

### Part 4: Open and Edit (Simple Practice)

1. Open any text file from your project (using the file tree or search)
2. Click inside the file
3. Make a tiny change (add a comment, change a word — anything)
4. Press `Cmd + S` to save
5. Notice the dot (if there was one) disappears from the filename tab

**Why this matters:** You need to know how to save changes. Quick and simple.

Once you've completed this task, you'll be ready for the real power: telling your AI assistant to edit files using the paths you've learned to copy.

The workflow will be:
1. You open a folder in VSCode
2. You copy a file's path
3. You tell AI: "Here's the path. Please edit it like this: [your instructions]"
4. AI does the work
