# Exercise: Mac Local Dev Environment Quick Setup

## Objective

Read the *[Mac Local Dev Environment Quick Setup](https://github.com/easyscale-academy/learn_dev_tools_basic-project/tree/02-Mac-Quick-Setup/)* tutorial, then install VS Code, Ghostty, and GitHub Desktop on your Mac and set up a clean project folder structure.

**Estimated time: 10–15 minutes**

## How-to Guide

1. **Read the tutorial first** — work through the full *Mac Local Dev Environment Quick Setup* tutorial before installing anything
2. Download and install **VS Code** from https://code.visualstudio.com
3. Download and install **Ghostty** from https://ghostty.org (optional — you can use the built-in Terminal instead)
4. Download and install **GitHub Desktop** from https://desktop.github.com/download/ and sign in with your GitHub account
5. Create a ``GitHub`` folder inside your Documents folder to organize your projects
6. Open your terminal (Ghostty or Terminal) and type ``mise`` to confirm it still works

> **Tip:** All three tools follow the same install pattern on Mac — download the ``.dmg``, drag the app to Applications, done. No command-line setup needed.

## Checklist

- [ ] **Install VS Code** — download from the official site, drag to Applications, and open it
- [ ] **Install Ghostty (or use built-in Terminal)** — download from ghostty.org and drag to Applications, or confirm you'll use the built-in Terminal app
- [ ] **Install GitHub Desktop** — download, install, and sign in with your GitHub account
- [ ] **Create project folder** — create a ``GitHub`` folder inside ``~/Documents/`` for organizing your Git repos
- [ ] **Verify mise** — open your terminal and type ``mise`` to confirm it works in your local environment

## Grading Rubric

- **VS Code installed:** VS Code opens from Applications without errors
- **Terminal ready:** Student has either Ghostty or the built-in Terminal available and can type commands in it
- **GitHub Desktop configured:** GitHub Desktop is installed and the student is signed in with their GitHub account
- **Project folder exists:** A ``GitHub`` folder exists at ``~/Documents/GitHub/`` (or a similar organized location under the User Folder)
- **mise works locally:** Running ``mise`` in the terminal displays help output, confirming the previous lesson's setup carries over to the local environment
